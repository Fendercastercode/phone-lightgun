# RetroSight website

The public site for RetroSight (your phone is the light gun), served by GitHub Pages at
https://fendercastercode.github.io/phone-lightgun/

- `index.html`: the home page (Win95 intro, cabinet video slots).
- `privacy.html`: the privacy policy linked from Google Play.
- `videos/`: clips for the cabinet screens. To fill a slot, add an MP4 here and set it in `const VIDEOS`
  near the bottom of `index.html` (slots: trailer, setup, gameplay, demo, grip).

This repo holds only the website. The app's code is not here.
